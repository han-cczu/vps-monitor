# 步骤 01 · 工程骨架

> 阶段 1 · 依赖：无 · 粗估 1–2 天 · 对应设计方案 §3、§11.1、附录 A

## 1. 目标

建立单仓与三端骨架：两个 Go 模块能编译、前端底座（Minimal starter + 从完整版拷的组件）能跑、CI 能做静态检查。这一步不写业务。

## 2. 范围

**做**：目录结构、Go 模块与依赖、前端底座整理与依赖补齐、Vite 代理、`/api/health`、CI 静态检查、Makefile。

**不做**：数据库、登录、任何页面（starter 自带的空白页保留即可）。

## 3. 前置条件

- 本机：Go 1.26、Node 24、npm 11、Docker 29（已确认）
- 模板：`E:\agentlearn\前端代码\minimal-starter-vite-ts-main`（底座）与 `minimal-vite-ts-main`（拷组件用）

## 4. 实现方案

### 4.1 目录与 Go 工作区

```
vps-monitor/
├── go.work                    use ./agent ./server ./proto
├── Makefile
├── .editorconfig  .gitignore  .gitattributes（*.sh 强制 LF）
├── proto/                     模块 vpsmon/proto：agent 与 server 共用的消息结构体
│   └── msg.go                 Hello、Metrics、Ping、Config… 只放 struct 与常量，零依赖
├── agent/                     模块 vpsmon/agent
│   ├── cmd/agent/main.go
│   └── internal/{config,collector,transport}/   空包，各放一个 doc.go
├── server/                    模块 vpsmon/server
│   ├── cmd/server/main.go
│   ├── internal/{config,api,store,hub,auth,audit}/   空包
│   └── web/embed.go           //go:embed dist  （dist 不存在时用占位 index.html）
├── web/                       前端
├── deploy/                    先放 .gitkeep
├── ci/                        GitHub Actions 工作流
└── docs/
```

依赖（先加进 go.mod，代码在后续步骤用到）：

| 模块 | 依赖 |
|---|---|
| server | `github.com/go-chi/chi/v5`、`github.com/gorilla/websocket`、`modernc.org/sqlite`、`github.com/pressly/goose/v3`、`github.com/golang-jwt/jwt/v5`、`golang.org/x/crypto`（argon2）、`gopkg.in/yaml.v3` |
| agent | `github.com/shirou/gopsutil/v4`、`github.com/prometheus-community/pro-bing`、`github.com/coder/websocket`、`gopkg.in/yaml.v3` |

`server/cmd/server/main.go` 先只做：解析 `VM_LISTEN`（默认 `:9000`），chi 路由挂 `GET /api/health` 返回 `{"ok":true,"version":"dev"}`，其余路径交给内嵌前端（SPA 回退）。

`Makefile` 目标：`dev-server`（`go run ./server/cmd/server`）、`dev-web`（`cd web && npm run dev`）、`build-agent`（两架构交叉编译到 `dist/agent/`，`-ldflags "-s -w -X main.version=$(VERSION)"`）、`build-web`、`build-server`（先 build-web 再 go build）、`lint`、`test`。

### 4.2 前端底座整理

1. 把 `minimal-starter-vite-ts-main` 复制为 `web/`，先 `git add` 原样提交一次（以后回头对比方便）。
2. `npm i`；再补依赖：

```
npm i swr zustand qrcode.react country-flag-icons apexcharts react-apexcharts sonner
```

3. 从完整版 `minimal-vite-ts-main/src` 拷入 `web/src`：
   - `components/chart/`（整目录）
   - `components/custom-data-grid/`
   - `components/custom-dialog/`
   - `components/snackbar/`
   - `components/empty-content/`
   - `components/custom-breadcrumbs/`
   - `sections/account/`（只留改密码相关：`account-layout.tsx`、`account-change-password.tsx`，其余删）
   拷完跑 `npx tsc --noEmit`，把断掉的 import 清干净（这些组件依赖 `minimal-shared`、`es-toolkit`，starter 已带）。
4. 修改：
   - `src/global-config.ts`：`appName: 'VPS Monitor'`；`auth.skip: false`；删掉 firebase/amplify/auth0/supabase 字段与对应 `ConfigValue` 类型。
   - `src/components/flag-icon/flag-icon.tsx`：改为 `import * as flags from 'country-flag-icons/react/3x2'`，按 `code.toUpperCase()` 取组件渲染；找不到时返回 null。
   - `vite.config.ts`：

```ts
server: {
  port: 8080, host: true,
  proxy: {
    '/api/ws': { target: 'ws://localhost:9000', ws: true },
    '/api': { target: 'http://localhost:9000', changeOrigin: true },
  },
},
```

   - `src/lib/axios.ts`：`baseURL` 留空（同源）；补上请求拦截器：从 `sessionStorage` 取 `JWT_STORAGE_KEY` 加 `Authorization: Bearer`（starter 的 `setSession` 只在登录时设置默认头，刷新页面后由 `checkUserSession` 重设，这里加拦截器兜底）；响应 401 → 清 session 并跳 `/auth/sign-in`。
   - `src/layouts/nav-config-dashboard.tsx`：先放"监控总览 / 节点 / 代理 / 订阅用户 / 告警 / 设置"六项占位，路径指向 `paths.dashboard.*`（在 `routes/paths.ts` 补齐）。
   - `src/_mock`：starter 里只被登录演示用到，`auth.skip=false` 后无用，删掉并清引用。
   - `.env.example`：`VITE_SERVER_URL=`（留空，同源）。
5. 主题默认深色：`src/theme/theme-config.ts` 或 settings 默认值里把 `colorScheme` 设为 `'dark'`（对齐参考截图；用户仍可在设置抽屉切换）。

### 4.3 CI

`ci/ci.yml`（放到 `.github/workflows/ci.yml`，`ci/` 只是仓库内的说明位置；实际路径必须是 `.github/workflows/`）：

- `go`：`go vet ./...`、`go test ./...`（在 `agent`、`server`、`proto` 三个模块各跑一次，或用 `go work` 下 `go test ./...`）
- `web`：`npm ci`、`npm run tsc:check`、`npm run lint`、`npm run build`

## 6. 验收标准

- [ ] `go build ./...` 在 `agent`、`server`、`proto` 三个模块都通过
- [ ] `make dev-server` 后 `curl localhost:9000/api/health` 返回 `{"ok":true,...}`
- [ ] `make dev-web` 后打开 `http://localhost:8080` 能看到 starter 登录页（此时登录会失败，正常）
- [ ] 浏览器访问 `http://localhost:8080/api/health` 被代理到 Go
- [ ] `npx tsc --noEmit`、`npm run lint`、`npm run build` 三者通过
- [ ] 国旗组件渲染本地 SVG（Network 面板里没有对 `purecatamphetamine.github.io` 的请求）
- [ ] `git log` 里有"starter 原样"与"整理后"两次独立提交
- [ ] CI 在 PR 上跑绿

## 7. 风险与注意

- 完整版组件互相引用，拷 `chart` 时可能连带 `components/chart/components/*`，按 tsc 报错补齐即可；不要把 `_mock` 数据一起拷进来。
- `country-flag-icons/react/3x2` 全量 import 体积约 300 KB（gzip 后小得多），可接受；若在意，改为按需 `import { CN, HK } from ...` 的映射表。
- Windows 下写的 `install.sh` 等脚本必须是 LF，`.gitattributes` 加 `*.sh text eol=lf`。
