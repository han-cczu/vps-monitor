## 4. 实现方案

### 4.1 TOTP

- 库 `github.com/pquerna/otp/totp`；密钥存 `users.totp_secret`（AES-GCM 加密，密钥派生自 `VM_JWT_SECRET`，避免库被拷走直接可用）
- `POST /api/auth/totp/setup` → 生成 secret，返回 `otpauth://` URL 与 `secret`（前端 `QRCodeSVG` 展示）；`POST /api/auth/totp/enable {code}` 校验成功才写 `totp_enabled=1`；`POST /api/auth/totp/disable {code}`
- 登录：`sign-in` 校验密码后若 `totp_enabled` → 返回 `{mfaRequired: true, ticket}`（ticket 为 5 分钟一次性随机串，内存保存）；`POST /api/auth/mfa {ticket, code}` → `{accessToken, user}`；防重放：同一 code 在 90 s 内不可复用（记最近使用的 code）
- 前端：`auth/view/jwt/sign-in-view.tsx` 加第二步（`mui-one-time-password-input` 六格）；设置页"安全"Tab：启用/禁用 TOTP 流程
- 找回：`server reset-totp {username}` 子命令（步骤 07 子命令族）

### 4.2 审计日志页

`GET /api/audit?page=&size=&actor=&action=&target_type=&from=&to=`；前端 `settings/audit`：`CustomDataGrid`，行展开显示 `before/after` JSON diff（简单的并排 `pre`）；保留 365 天（rollup 里清理）。

### 4.3 agent 自动更新

- 面板镜像自带的 agent 版本作为"当前 agent 版本"（`/app/agent-dist/VERSION`）；节点列表显示 `agent_version` 并在低于当前时标"可更新"
- 消息 `agent.update {version, file, sha256}`（`proto`）：agent 下载 `{base}/agent/{file}`（复用 corefiles 的 token 下载中间件或公开路径均可，这里走公开 `/agent/` 路径，校验 sha256）→ 写 `.new` → `chmod` → `rename` 覆盖自身 → `syscall.Exec` 重启自身（或 `systemctl restart vps-agent`，二者择一，优先后者由 systemd 接管）
- API：`POST /api/servers/{id}/agent/update`、`POST /api/servers/agent/update-all`（仅在线且版本低于当前）
- 安全：agent 只接受面板下发的版本号与 sha，下载地址只拼面板 base；回退：更新失败保留旧二进制（`.new` 校验失败即删）

### 4.4 设置页收口 `settings/site`

时区（影响账期与到期判断，改动后提示"下次滚动生效"）、流量单位 1000/1024（前端 `format.ts` 读设置）、保留天数（metrics 分钟/小时、ping、审计）、告警冷却、站点标题；全部走 `GET/PUT /api/settings`（白名单键）。

### 4.5 日志与磁盘

- agent 安装 sing-box 时写 `/etc/logrotate.d/sing-box`（daily、rotate 7、compress、copytruncate）；无 logrotate 的系统由 agent 每日自检文件大于 50 MB 时截断
- 面板：SQLite 每周 `PRAGMA optimize`；`wal_checkpoint(TRUNCATE)` 每日
- Caddy：`/sub/*` 的 query 删除 `token`；access log 轮转 `roll_size 50mb roll_keep 5`

### 4.6 手机适配收尾

逐页在 400 px 宽检查：总览卡片单列、详情页图表高度自适应、DataGrid 列在窄屏隐藏次要列（`columnVisibilityModel` 按断点）、对话框全屏（`fullScreen` on `sm` 以下）、代理详情两列变单列、订阅二维码尺寸自适应。

### 4.7 安全核对（设计方案 §13 逐条）

| 条目 | 核对方式 |
|---|---|
| agent 白名单 | 向 agent 发未知/畸形消息，只留日志 |
| 面板私有 | 未登录访问任何 `/api/*`（除白名单）401；`/dashboard/*` 前端跳登录 |
| token 分离 | 节点 token 泄露只影响该节点；重置后旧 token 失效 |
| sing-box API 仅本机 | 节点上 `ss -lntp` 看 10085 绑定 127.0.0.1 |
| 证书 pin | Clash 改错指纹连不上 |
| 审计 | 抽查 10 个写操作均有记录且脱敏 |
| 传输 | 全部 HTTPS/WSS；HTTP 跳转 |
| 供应链 | agent 与 sing-box 下载均校验 sha256 |
| 依赖漏洞 | `govulncheck ./...`、`npm audit --omit=dev` 无高危 |

### 4.8 runbook 定稿

安装、升级（面板 / agent / sing-box 三条路径）、备份恢复、初始密码与 TOTP 找回、节点迁移（换 IP 后改 `public_host` 即可）、常见故障（agent 不在线、下发失败回滚、订阅为空、QUIC 不通）。

## 6. 验收标准

- [ ] 启用 TOTP 后登录需要验证码；错误码拒绝；同一码 90 s 内重放拒绝；`reset-totp` 子命令可解除
- [ ] 审计页能按操作者/动作/时间筛选并查看 before/after
- [ ] 发布新版面板镜像后，节点列表出现"可更新"，一键更新全部，1 分钟内版本号刷新且 agent 未离线超过 10 s
- [ ] 单位切换 1024 后卡片数值随之变化；时区改动记录在审计
- [ ] sing-box 日志按天轮转；面板 WAL 文件不无限增长
- [ ] Caddy 访问日志里 `/sub/` 请求不含 token
- [ ] 手机（真机）走完：登录 → 总览 → 详情 → 代理 → 订阅用户 → 扫码，无横向滚动、无被遮挡按钮
- [ ] 安全核对表全部通过；`govulncheck`、`npm audit` 无高危
- [ ] `runbook.md` 覆盖 4.8 全部条目

## 7. 风险与注意

- agent 自更新时若新版本启动即崩，systemd `Restart=always` 会循环重启——更新前用 `vps-agent --version` 验证新二进制能执行；仍失败可用步骤 04 的安装脚本重装。
- TOTP secret 加密后，换 `VM_JWT_SECRET` 会导致无法解密，runbook 里写明"改密钥前先禁用 TOTP"。
