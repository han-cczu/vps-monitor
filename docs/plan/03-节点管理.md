# 步骤 03 · 节点管理

> 阶段 1 · 依赖：02 · 粗估 2 天 · 对应设计方案 §4.3、§8.2、§7.4

## 1. 目标

能在面板里添加节点、拿到 agent token 与一键安装命令；节点列表与编辑表单可用。表单包含账单与流量套餐字段（结算逻辑在步骤 18，这里只存）。

## 2. 范围

**做**：`servers`、`server_host_info` 两张表；CRUD 接口；token 生成与重置；安装命令拼装；`/install.sh` 与 `/agent/{file}` 的静态托管位置；前端节点列表页与表单。

**不做**：在线状态（步骤 05 才有，这里显示"未连接"）、实际的 install.sh 内容（步骤 04）。

## 3. 前置条件

步骤 02 完成。

## 4. 实现方案

### 4.1 迁移 `0002_servers.sql`

```sql
CREATE TABLE servers (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL, region TEXT NOT NULL DEFAULT '', group_name TEXT NOT NULL DEFAULT '',
  tags TEXT NOT NULL DEFAULT '[]', sort_order INTEGER NOT NULL DEFAULT 0,
  token_hash TEXT NOT NULL UNIQUE, public_host TEXT NOT NULL DEFAULT '',
  price REAL NOT NULL DEFAULT 0, currency TEXT NOT NULL DEFAULT 'CNY',
  billing_cycle TEXT NOT NULL DEFAULT 'month',        -- month | quarter | year | once
  expire_at TEXT, auto_renew INTEGER NOT NULL DEFAULT 0,
  traffic_limit INTEGER NOT NULL DEFAULT 0, traffic_reset_day INTEGER NOT NULL DEFAULT 1,
  traffic_mode TEXT NOT NULL DEFAULT 'max',           -- out | in | sum | max
  bandwidth_label TEXT NOT NULL DEFAULT '', note TEXT NOT NULL DEFAULT '',
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE TABLE server_host_info (
  server_id INTEGER PRIMARY KEY REFERENCES servers(id) ON DELETE CASCADE,
  hostname TEXT, os TEXT, kernel TEXT, arch TEXT, cpu_model TEXT, cores INTEGER,
  mem_total INTEGER, disk_total INTEGER, boot_time INTEGER,
  ipv4 INTEGER, ipv6 INTEGER, public_ip TEXT, agent_version TEXT, updated_at INTEGER
);
```

### 4.2 服务端

- `store/servers.go`：`List`、`Get`、`Create`、`Update`、`Delete`、`FindByTokenHash`、`UpdateTokenHash`；`store/hostinfo.go`：`Upsert`、`Get`。
- token：`crypto/rand` 32 字节 → base64url（43 字符）；只存 `sha256` hex。创建与重置接口把明文放在响应里返回一次。
- 校验：`name` 1–64；`region` 空或 ISO 3166-1 alpha-2（大写两字母）；`tags` ≤ 10 个、每个 ≤ 16 字；`billing_cycle`/`traffic_mode` 枚举；`traffic_reset_day` 1–31；`expire_at` `YYYY-MM-DD` 或 null；`public_host` 空或合法 host/IP。
- 安装命令拼装 `api/servers.go: installCommand(publicURL, token)`：

```
curl -fsSL {PUBLIC_URL}/install.sh | bash -s -- --server {wss://host}/api/agent/ws --token {token}
```

`PUBLIC_URL` 为空时用请求的 `Host` 与协议推断（开发环境）。
- 静态托管：`GET /install.sh`、`GET /agent/{file}` 从 `{DataDir}/agent/` 读（步骤 07 的镜像会把 CI 产物放进去；开发时手动 `make build-agent` 后拷）。文件名白名单 `^vps-agent-linux-(amd64|arm64)$`、`install.sh`、`uninstall.sh`。
- 列表接口返回值预留 `online: false, last_seen: null, host: {...}` 字段，步骤 05 填。
- 全部写接口记审计（`server.create/update/delete/token_reset`），`before/after` 里不含 token。

### 4.3 前端 `sections/servers/`

- `list/servers-list-view.tsx`：`CustomDataGrid`，列：名称（带国旗）、地区、分组、标签（`Label`）、状态（占位"未连接"）、到期、操作（编辑、token、删除）。顶部"新增节点"。
- `form/server-form.tsx`：`Dialog` 内 `Tabs`：
  - 基础：名称、地区（下拉：常用国家码 + 自由输入）、分组、标签（多值输入）、排序、备注
  - 接入：公网地址 `public_host`；（编辑态）"重置 token"按钮
  - 账单：价格、货币（CNY/USD/HKD/EUR…）、周期、到期日（`DatePicker`）、自动顺延
  - 套餐：流量上限（数字 + 单位 GB/TB 选择，存字节）、重置日、统计模式（四选一，带一句说明）、带宽标签
  RHF + zod，字段校验与后端一致。
- `token-dialog.tsx`：创建成功或重置后弹出，显示 token 与一键安装命令，复制按钮，提示"只显示一次"。
- `api/servers.ts`：`useServers()`（SWR）、`createServer`、`updateServer`、`deleteServer`、`resetToken`。
- 路由：`/dashboard/servers`、`/dashboard/servers/new`（可用 dialog 代替独立页）、`/dashboard/servers/:id/edit`。

## 5. 接口与数据

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/servers` | 列表，含 `online/last_seen/host`（占位） |
| POST | `/api/servers` | 创建 → `{server, token, installCommand}` |
| GET | `/api/servers/{id}` | 单个 |
| PUT | `/api/servers/{id}` | 更新 |
| DELETE | `/api/servers/{id}` | 删除（级联 host_info；后续表也级联） |
| POST | `/api/servers/{id}/token` | 重置 → `{token, installCommand}` |
| GET | `/install.sh`、`/agent/{file}` | 静态托管（公开，无鉴权） |

## 6. 验收标准

- [ ] 新增节点后弹出 token 与安装命令，刷新列表后 token 不再可见
- [ ] 重置 token 后旧 token 的哈希不再匹配（`FindByTokenHash` 返回空）
- [ ] 四个 Tab 的字段都能保存并回显；无效值（如 `traffic_reset_day=40`、`region=china`）被前后端同时拦下
- [ ] 删除节点二次确认；`server_host_info` 级联删除
- [ ] `audit_log` 中有创建/更新/删除/重置 token 记录且不含明文 token
- [ ] `/install.sh` 在文件不存在时返回 404 而不是 500
- [ ] 手机宽度下表单可用（Tab 可滚动）

## 7. 风险与注意

- `tags` 与 `traffic_limit` 的单位换算放前端 `utils/format.ts`，后端只认字节。
- 节点删除会在后续步骤级联删掉大量数据（指标、入站、修订），删除确认文案要写清。
