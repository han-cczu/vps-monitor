### 4.1 迁移 `0006_proxy.sql`

```sql
CREATE TABLE inbounds (
  id INTEGER PRIMARY KEY, server_id INTEGER NOT NULL REFERENCES servers(id) ON DELETE CASCADE,
  tag TEXT NOT NULL, protocol TEXT NOT NULL,            -- vless | shadowsocks | hysteria2 | tuic

CREATE TABLE node_core (
  server_id INTEGER PRIMARY KEY REFERENCES servers(id) ON DELETE CASCADE,

  firewall TEXT, last_error TEXT, updated_at INTEGER

CREATE TABLE config_revisions (
  server_id INTEGER NOT NULL REFERENCES servers(id) ON DELETE CASCADE,
  revision INTEGER NOT NULL, config_json TEXT NOT NULL, sha256 TEXT NOT NULL,
  created_at INTEGER NOT NULL, created_by TEXT NOT NULL,
  PRIMARY KEY (server_id, revision)
);
CREATE TABLE node_advanced (
  server_id INTEGER PRIMARY KEY REFERENCES servers(id) ON DELETE CASCADE,
  extra_json TEXT NOT NULL DEFAULT '{}', updated_at INTEGER
);
CREATE TABLE subscribers (
  id INTEGER PRIMARY KEY, name TEXT NOT NULL, note TEXT NOT NULL DEFAULT '',
  enabled INTEGER NOT NULL DEFAULT 1, auto_disabled TEXT NOT NULL DEFAULT 'none',   -- none | quota | expired
  sub_token TEXT NOT NULL UNIQUE, uuid TEXT NOT NULL, password TEXT NOT NULL, ss_user_key TEXT NOT NULL,

  period_start INTEGER NOT NULL, expire_at TEXT, created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL

CREATE TABLE subscriber_assignments (
  subscriber_id INTEGER NOT NULL REFERENCES subscribers(id) ON DELETE CASCADE,
  inbound_id INTEGER NOT NULL REFERENCES inbounds(id) ON DELETE CASCADE,
  PRIMARY KEY (subscriber_id, inbound_id)
);
CREATE TABLE subscriber_traffic (
  subscriber_id INTEGER NOT NULL REFERENCES subscribers(id) ON DELETE CASCADE,
  server_id INTEGER NOT NULL, period_start INTEGER NOT NULL,
  up_bytes INTEGER NOT NULL DEFAULT 0, down_bytes INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (subscriber_id, server_id, period_start)

CREATE TABLE subscriber_traffic_daily (
  subscriber_id INTEGER NOT NULL REFERENCES subscribers(id) ON DELETE CASCADE,
```

### 4.2 入站 settings 结构 `proxy/model/inbound.go`

```go
type VlessSettings      struct { HandshakeServer string; HandshakePort int; PrivateKey, PublicKey string; ShortIDs []string }
type ShadowsocksSettings struct { Method string; ServerPSK string }            // Method 固定 2022-blake3-aes-128-gcm
type Hysteria2Settings  struct { ObfsEnabled bool; ObfsPassword string; UpMbps, DownMbps int; IgnoreClientBandwidth bool }
type TuicSettings       struct { CongestionControl string; ZeroRTT bool }      // bbr | cubic | new_reno
func ParseSettings(protocol string, raw json.RawMessage) (any, error)
func (i *Inbound) Validate() error
```

- `tag` 由服务端生成 `{简称}-{port}`（`vless`、`ss`、`hy2`、`tuic`），不可手改。
- 端口占用校验：同一节点内 `(port, transport)` 唯一——vless 占 tcp；shadowsocks 占 tcp+udp；hysteria2、tuic 占 udp。同一端口 vless + hysteria2 合法，shadowsocks + tuic 冲突。
- 创建时按协议自动生成缺失的密钥字段；`regenerate-keys` 重生全部密钥字段（Reality 密钥对、short_id / 服务端 PSK / 混淆密码）。
- 首次创建 hysteria2 或 tuic 入站时若该节点无证书，自动生成（sni 默认 `www.bing.com`）。

### 4.3 密钥 `proxy/keys`

| 函数 | 实现 |
|---|---|
| `UUID() string` | `crypto/rand` 16 字节，设 v4/variant 位，格式化 |
| `X25519() (priv, pub string)` | 32 字节随机私钥（clamp）→ `curve25519.X25519(priv, Basepoint)`；两者 `base64.RawURLEncoding` |
| `ShortID() string` | 8 字节随机 hex（16 字符） |
| `PSK16() string` | 16 字节随机，`base64.StdEncoding` |
| `Password24() string` | 24 字节随机，`base64.RawURLEncoding` |
| `SubToken() string` | 32 字节随机，`base64.RawURLEncoding`（43 字符） |

单测：长度、格式、多次调用不重复、X25519 公钥可由私钥重新推导一致。

### 4.4 证书 `proxy/certs`

```go
func Generate(sni string, now time.Time) (Cert, error)   // Cert{CertPEM, KeyPEM, FingerprintSHA256, NotAfter}
```

ECDSA P-256；`SerialNumber` 随机 128 位；`Subject.CN = sni`、`DNSNames = [sni]`；`NotBefore = now-1h`、`NotAfter = now+3650d`；`KeyUsage` 数字签名 + 密钥协商，`ExtKeyUsage ServerAuth`；`IsCA=false`。指纹 = `sha256(DER)` 大写 hex 用 `:` 分隔。单测：解析回 `x509.Certificate`、字段正确、指纹与 `openssl x509 -fingerprint -sha256` 一致（测试里用 Go 重新计算即可）。

### 4.5 订阅用户 `proxy/subscribers.go`

- 创建：生成 `uuid`、`password`、`ss_user_key`、`sub_token`；`period_start = 今天 00:00（面板时区）`；`reset_day` 0–31；`expire_at` 可空。
- `PUT /assignments { inbound_ids: [...] }` 全量替换；校验 inbound 存在。
- `POST /reset-token`、`POST /regenerate-credentials`（确认后重生三项凭据，旧订阅立刻失效）、`POST /reset-usage`（`traffic_used=0`，`auto_disabled` 若为 quota 则清为 none）。
- 查询返回附带 `assigned_inbounds:[{inbound_id, server_id, server_name, protocol, port}]` 与 `servers_count`。

### 4.6 变更通知钩子

`proxy.Notifier` 接口 `NodeChanged(serverID int64, reason string)`；所有会影响某节点渲染结果的写操作（入站增删改/启停、证书重生、分配变更、订阅用户启停/凭据重生/删除、高级 JSON）调用它。本步注入 `NoopNotifier`，步骤 13 换成真正的 reconciler。分配变更要把**变更前后**涉及的节点都通知到。

### 4.7 API 一览

| 方法 | 路径 |
|---|---|
| GET / POST | `/api/servers/{id}/inbounds` |
| GET / PUT / DELETE | `/api/inbounds/{id}` |
| POST | `/api/inbounds/{id}/regenerate-keys` |
| GET | `/api/servers/{id}/cert` （不返回 key_pem） |
| POST | `/api/servers/{id}/cert/regenerate { sni? }` |
| GET / PUT | `/api/servers/{id}/advanced` |
| GET | `/api/servers/{id}/core` （本步返回 node_core 行，多为空值） |
| GET / POST | `/api/subscribers` |
| GET / PUT / DELETE | `/api/subscribers/{id}` |
| PUT | `/api/subscribers/{id}/assignments` |
| POST | `/api/subscribers/{id}/reset-token`、`/regenerate-credentials`、`/reset-usage` |

订阅用户的凭据与 `sub_token` 前端需要展示（生成链接、二维码），所以详情接口返回全部字段；列表接口不带凭据与 token，只带状态与用量。

## 7. 风险与注意

- Reality 密钥编码必须是 `base64url` 无填充，sing-box 与 Clash 都按此解析。
- SS2022 `aes-128` 方法的 PSK 必须恰好 16 字节，`aes-256` 要 32 字节——本方案固定 128。
- `subscribers.period_start` 用面板时区当日零点，后续限额与重置都以此为准。
