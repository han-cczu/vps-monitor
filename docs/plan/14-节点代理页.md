# 步骤 14 · 节点代理页

> 阶段 3 · 依赖：13 · 粗估 4 天 · 对应设计方案 §4.5、§11.2、§11.6

## 1. 目标

前端有"代理"模块：各节点核心状态一览；每节点一页管理核心（安装/升级/重启/日志/修订回滚）、入站（四协议表单）、证书。

## 2. 范围

**做**：`/dashboard/proxy` 一览、`/dashboard/proxy/:serverId` 详情页及其全部组件、`api/proxy.ts`。

**不做**：订阅用户页与订阅链接（15）、高级 JSON 编辑器（17，本步只显示是否已配置）。

## 3. 前置条件

步骤 13 的接口全部可用。

## 4. 实现方案

### 4.1 数据层 `web/src/api/proxy.ts`

SWR hooks：`useCore(serverId)`（`refreshInterval: 5000`，且监听快照 `core` 字段变化触发 `mutate`）、`useInbounds(serverId)`、`useCert(serverId)`、`useRevisions(serverId)`；mutation：`installCore`、`restartCore`、`applyCore`、`fetchLogs`、`rollback`、`createInbound`、`updateInbound`、`deleteInbound`、`regenerateKeys`、`regenerateCert`。统一错误 toast（`sonner`）。

### 4.2 一览页 `sections/proxy/list/proxy-list-view.tsx`

`CustomDataGrid`，每行一个节点：名称（国旗）、agent 在线、核心（未安装 / 已安装 vX / 运行中 / 已停止，用 `Label` 色彩：未安装灰、运行绿、停止红、待应用黄）、版本与托管版本是否一致（不一致显示"可升级"）、入站数、用户数、最后错误（截断 + tooltip）、操作"管理"。顶部提示当前托管版本。

### 4.3 详情页 `sections/proxy/detail/`

| 组件 | 内容 |
|---|---|
| `proxy-detail-view.tsx` | 面包屑（代理 / 节点名）；左列 `CoreStatusCard` + `CertCard`；右列 `InboundList`；宽度不足时纵向堆叠 |
| `core-status-card.tsx` | 状态 `Label`；已安装版本 vs 托管版本；运行状态；`applied / desired` 修订号（不一致显示"待应用"与转圈）；监听端口 chips（`443/tcp`…）；防火墙类型（`none` 时警示条："本机无防火墙管理，请确认云安全组已放行以上端口"）；最后错误（可展开完整）。按钮：安装/升级（版本不一致时文案"升级到 vX"，确认框说明会断连几秒）、重启、重新下发、查看日志、修订历史。agent 离线时按钮禁用并提示 |
| `log-drawer.tsx` | 右侧 `Drawer`，行数选择 100/200/500，刷新按钮，`pre` 等宽、自动滚到底、可复制 |
| `revisions-dialog.tsx` | 列表（修订号、时间、来源、sha 前 8 位、是否当前已应用）；"查看"打开 JSON（只读，等宽，`overflow auto`）；"回滚到此修订"二次确认 |
| `cert-card.tsx` | 伪装 SNI、指纹（可复制）、有效期至；"重新生成"确认框文案："重新生成后所有 Hysteria2 / TUIC 订阅中的指纹失效，客户端需刷新订阅"。无证书时显示"创建 Hysteria2 或 TUIC 入站时自动生成" |
| `inbound-list.tsx` | 每行：协议 `Label`（VLESS / SS / HY2 / TUIC 各一色）、端口（含 tcp/udp 标注）、备注、启用 `Switch`（即时保存）、用户数、本期流量（内存计数，来自 core 接口）；操作：编辑、重生密钥、删除；顶部"新增入站" |
| `inbound-form.tsx` | `Dialog`；第一步选协议（四张带一句说明的选项卡；编辑态不可改协议）；第二步按协议显示字段（见 4.4）；生成的密钥只读展示 + 复制；保存后 toast "已保存，正在下发"；错误（如端口冲突）显示后端 `message` |
| `advanced-hint.tsx` | 一行：是否配置了高级 JSON（步骤 17 加编辑入口） |

### 4.4 表单字段与 zod

```ts
const base = z.object({ listen_port: z.number().int().min(1).max(65535), remark: z.string().max(64), enabled: z.boolean() });
const vless = base.extend({ protocol: z.literal('vless'),
  handshake_server: z.string().min(1), handshake_port: z.number().int().default(443), short_ids: z.array(z.string().regex(/^[0-9a-f]{2,16}$/)).min(1) });
const ss = base.extend({ protocol: z.literal('shadowsocks') });                  // 方法固定
const hy2 = base.extend({ protocol: z.literal('hysteria2'),
  obfs_enabled: z.boolean(), up_mbps: z.number().int().min(0).optional(), down_mbps: z.number().int().min(0).optional(), ignore_client_bandwidth: z.boolean() });
const tuic = base.extend({ protocol: z.literal('tuic'), congestion_control: z.enum(['bbr','cubic','new_reno']), zero_rtt: z.boolean() });
export const inboundSchema = z.discriminatedUnion('protocol', [vless, ss, hy2, tuic]);
```

默认端口建议：vless 443、ss 8388、hy2 8443、tuic 8444；协议选择后自动填充未被占用的建议端口（用 `useInbounds` 数据判断）。密钥字段（Reality 私钥/公钥、PSK、混淆密码）不在表单里编辑，由后端生成，表单只展示。

### 4.5 实时联动

快照里 `core.running / pending / error` 变化时（`useServer(id)` 的 selector），`mutate` 核心接口；"重新下发"后按钮进入 loading 直到 `pending=false` 或 60 s。

### 4.6 路由与导航

`paths.dashboard.proxy.root = '/dashboard/proxy'`、`.detail(id)`；导航项"代理"；节点卡片"更多"菜单加"代理管理"直达。

## 5. 接口与数据

消费步骤 12/13 的接口，无新增后端接口。

## 7. 风险与注意

- `Switch` 即时保存会触发下发，连点会被服务端 debounce 合并，但前端要防重复请求（禁用直到响应）。
- JSON 查看用 `pre` 即可，不引 Monaco。
- 协议 `Label` 颜色四种固定，与订阅用户页复用。

## 8. 产出物

`web/src/api/proxy.ts`、`web/src/sections/proxy/{list,detail}/*`、路由与导航项。

## 9. 偏离记录

1. 沿用项目已配置的 MUI DataGrid 及自定义工具栏；无新增后端接口或依赖。列表定时汇总每节点 core/inbounds，单节点接口失败只影响对应行；详情 core 每 5 s 刷新并响应快照 core/online 字段变化。
2. 现有入站接口没有人数，复用不含凭据的 subscribers 列表计算“分配用户（含停用）”，节点内去重；这与快照中“目标配置有效用户数”是不同口径。
3. 内存入站计数在面板重启后清零，界面明确标注“面板本次运行累计”，不用“本期流量”。
4. Agent 的 listening 来自整台节点的 /proc，包含其它进程和回环统计端口。标题改为“节点监听端口”，防火墙提示要求按启用入站检查云安全组，不要求放行全部监听端口。
5. 首次 VLESS 创建可留空 Short IDs 自动生成；编辑至少保留一项。校验偶数长度、小写十六进制、唯一性及 16 项上限；10085/tcp 为统计保留端口。密钥只读/默认遮蔽，保存时不回传生成字段，避免覆盖并发重生。
6. TUIC 无独立入站密钥，隐藏其重生入口并说明使用用户凭据/节点证书。保存提示为“等待节点应用”，覆盖离线/未安装场景；离线仍可编辑配置和查看历史，操作核心与回滚禁用。
7. 重新下发等待响应中的确切修订号/哈希/版本达到运行状态，最多 60 s；保存成功后的刷新失败显示资源错误，不把已成功写入误报为保存失败。
8. 日志显示与复制移除终端颜色控制符；切换/关闭取消请求，忽略主动取消的网络错误提示。回滚二次确认说明不会改写表单数据。
