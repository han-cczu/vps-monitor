## 4. 实现方案

### 4.1 迁移 `0009_traffic.sql`

```sql
CREATE TABLE traffic_counters (
  server_id INTEGER PRIMARY KEY REFERENCES servers(id) ON DELETE CASCADE,
  last_rx INTEGER NOT NULL, last_tx INTEGER NOT NULL, last_ts INTEGER NOT NULL
);
CREATE TABLE traffic_periods (
  server_id INTEGER NOT NULL REFERENCES servers(id) ON DELETE CASCADE,
  period_start INTEGER NOT NULL, period_end INTEGER,          -- NULL = 当前账期
  in_bytes INTEGER NOT NULL DEFAULT 0, out_bytes INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (server_id, period_start)
);
```

### 4.2 结算 `server/internal/traffic`

```go
type Accountant struct { mu; counters map[int64]counter; periods map[int64]*period; dirty set }
func (a *Accountant) OnMetrics(serverID, m proto.Metrics)   // 挂 hub 钩子
func (a *Accountant) Flush(ctx)                             // 每 60 s 持久化 counters 与当前账期
func (a *Accountant) Rollover(ctx, today time.Time)         // 每日 00:00
func Used(p period, mode string) int64                      // out | in | sum | max
```

`OnMetrics`：

```
if 无 counter: counter = {rx, tx, ts}; return                     // 首次不计
dRx = rx - last_rx; dTx = tx - last_tx
if dRx < 0: dRx = rx   // 重启归零；同理 dTx
period.in += dRx; period.out += dTx; counter = {rx, tx, ts}
```

注意 agent 重启（非机器重启）计数器不变，不会误加。

`Rollover`：对每个节点，若 `今天日号 == traffic_reset_day`（或 reset_day 大于当月天数且今天是月末）→ 当前账期 `period_end = 今天零点`，新建 `period_start = 今天零点`。启动时补跑漏掉的日子（同步骤 16 的 `last_rollover_date` 机制，共用 settings 键 `traffic.last_rollover_date`）。

启动时从库加载 counters 与当前账期到内存。

### 4.3 快照与接口

- 快照 `servers[].traffic = {used, limit, mode, in, out, period_start, period_end_expected}`（`limit=0` 表示不限；前端显示 ∞）
- `GET /api/servers/{id}/traffic?months=12` → 历史账期列表 `[{period_start, period_end, in, out, used}]`（用节点当前 mode 计算 used）
- 节点列表接口增加 `traffic_used / traffic_limit`

### 4.4 到期与自动顺延 `server/internal/billing`

每日 00:05：`expire_at < 今天 && auto_renew` → 按 `billing_cycle` 顺延（month +1 月、quarter +3 月、year +1 年；`once` 不顺延），可能需多次累加直到大于今天（长时间停机）；审计 `actor=system, action=server.auto_renew`。事件 `ServerExpiringSoon`（7/3/1 天，19 用）在同一任务里计算并发出（每天一次，不重复）。

### 4.5 前端补齐

- 卡片 `traffic-row.tsx`：`剩余流量 {limit-used}`（不限时 `∞`），右侧 `{used} / {limit|∞}`；20 段 `SegmentBar` 按已用比例着色（>80% 橙、>95% 红）；不限额时进度条显示为浅色空条
- 卡片 `card-footer.tsx`：`到期 N 天`（N 小于 7 红、小于 30 橙；`once` 且无到期显示 `—`）；带宽标签、价格标签（`formatPrice`：`¥99/年`、`$10.79/月`、`一次性`）
- 汇总条：`本月总流量`（全部节点当前账期 used 之和）、`7 天内到期 N 台`
- 节点列表新增列：到期、本期用量/上限、模式
- 详情页新增"账单与流量"面板：价格/周期/到期/自动顺延；账期表格（近 12 期）；本期进度
- 排序选项新增"到期最近"、"剩余流量最少"

- [ ] 单测：`Used` 四种模式；重启归零的 delta；月末重置日（31 号在 30 天月）；顺延多期

- [ ] 手工把 `traffic_reset_day` 设为明天并把时钟/日期推进（或直接调用 Rollover）→ 出现新账期，旧账期 `period_end` 填上
- [ ] 卡片剩余流量、进度条、到期天数、带宽/价格标签与参考截图布局一致；`limit=0` 显示 ∞
- [ ] `max` 模式下 used 等于 in/out 较大者（与 Komari 截图行为一致）
- [ ] `expire_at` 设为昨天 + `auto_renew` + `year` → 次日变为明年同日；`once` 不变
- [ ] 详情页账单面板与账期表格正确
- [ ] 截图核对表全部 ✔

## 7. 风险与注意

- 首条 metrics 不计入（无基线），面板重启也只丢一秒。
- 账期滚动与订阅用户账期滚动是两套（节点 vs 人），共用"每日零点"调度器但分别实现。
- `vnstat` 与我们的统计口径（网卡过滤）可能不同，验收只看量级。

## 9. 偏离记录

- 设计方案卡片"出站/入站累计"未定义口径；本步定为**当前账期内累计**（与剩余流量口径一致），而不是自开机累计。

- 每分钟统一调用补滚动，在线首条跨月样本也会立即滚动；逐个漏过的账期补齐，不依赖仅比较“今天日号”。保留 `traffic.last_rollover_date` 供运维观察，恢复计算以当前持久账期为准。
- 新增唯一当前账期索引和 `billing_reminders` 表，保护并发/重启幂等。流量计数器和账期同事务提交；首条不计、重复/乱序忽略。强杀加机器归零不能保证只丢一秒，停机跨账期增量归当前期，不补造分时用量。
- 沿用已有 card-rows.tsx 中的 TrafficRow/CardFooter；流量条可配置 20 段及 80/95 配色，其余资源条保持 10 段。节点详情直接追加完整账单面板。
