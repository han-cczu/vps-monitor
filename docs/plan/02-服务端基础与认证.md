# 步骤 02 · 服务端基础与认证

> 阶段 1 · 依赖：01 · 粗估 2 天 · 对应设计方案 §6.1、§6.7、§8.1

## 1. 目标

服务端有配置、有数据库、有登录。前端 starter 的登录页对接真实后端，登录后进入空的 dashboard。

## 2. 范围

**做**：配置加载、SQLite 打开与迁移框架、`users`/`settings`/`audit_log` 三张表、argon2id 密码、JWT 签发校验、登录限速、初始管理员、改密码、审计记录、请求日志、内嵌前端与 SPA 回退。

**不做**：TOTP（步骤 20）、任何业务表。

## 3. 前置条件

步骤 01 完成。

## 4. 实现方案

### 4.1 配置 `server/internal/config`

```go
type Config struct {
    Listen     string        // VM_LISTEN, 默认 ":9000"
    DataDir    string        // VM_DATA_DIR, 默认 "./data"
    PublicURL  string        // VM_PUBLIC_URL, 如 https://panel.example.com；为空时安装命令用请求的 Host 拼
    JWTSecret  string        // VM_JWT_SECRET, 为空则首次启动生成并写入 {DataDir}/jwt.secret（0600）
    TZ         string        // VM_TZ, 默认 Asia/Shanghai
    LogLevel   string        // VM_LOG_LEVEL, 默认 info
}
func Load() (Config, error)   // 只读环境变量，不读文件
```

启动时 `time.LoadLocation(cfg.TZ)`，全局 `clock.Location` 供结算类任务使用。

### 4.2 存储 `server/internal/store`

- `Open(path) (*DB, error)`：DSN `file:{path}?_pragma=journal_mode(WAL)&_pragma=busy_timeout(5000)&_pragma=foreign_keys(1)&_pragma=synchronous(NORMAL)`；`SetMaxOpenConns(1)` 写、另开一个只读连接池给查询（SQLite 单写者，简单起见先用一个 `*sql.DB`，`MaxOpenConns=4`，写操作走事务）。
- 迁移：`migrations/` 目录 `//go:embed`，goose `SetBaseFS` + `Up`。
- `0001_init.sql`：

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY, username TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL, totp_secret TEXT, totp_enabled INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL
);
CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);
CREATE TABLE audit_log (
  id INTEGER PRIMARY KEY, ts INTEGER NOT NULL, actor TEXT NOT NULL, action TEXT NOT NULL,
  target_type TEXT NOT NULL, target_id TEXT, before TEXT, after TEXT, ip TEXT
);
CREATE INDEX idx_audit_ts ON audit_log(ts);
```

- repo 风格：每张表一个文件 `users.go`、`settings.go`、`audit.go`，方法签名带 `ctx`；`settings` 提供 `Get(key, &v)` / `Set(key, v)`，值 JSON 序列化。

### 4.3 认证 `server/internal/auth`

- 密码：`argon2.IDKey(pw, salt, 3, 64*1024, 2, 32)`，编码为 `$argon2id$v=19$m=65536,t=3,p=2$salt$hash`。
- JWT：HS256，claims `{sub: userID, name, role: "admin", exp: now+12h, iat}`；`Middleware` 读 `Authorization: Bearer`，失败 401 `{message:"unauthorized"}`；把 user 放进 ctx。
- 登录限速 `ratelimit.go`：`map[ip]*bucket`，15 分钟窗口 5 次失败即锁 15 分钟，后台 goroutine 每分钟清理；被锁返回 429 `{message:"too many attempts"}`。
- 初始管理员：启动时 `users` 为空 → 创建 `admin`，密码 16 位随机（大小写数字），**只打印到日志一次**：`initial admin password: ...`。
- handler：
  - `POST /api/auth/sign-in` body `{email, password}`（starter 字段名叫 email，按 username 用）→ `200 {accessToken, user}`；失败 401 `{message:"用户名或密码错误"}`
  - `GET /api/auth/me` → `{user}`
  - `POST /api/auth/password` body `{oldPassword, newPassword}`（新密码 ≥ 10 位）→ 204；写审计
- `user` 对象形状对齐 starter `src/auth/types.ts`：`{ id, displayName, email, photoURL: null, role: "admin" }`。

### 4.4 审计 `server/internal/audit`

```go
func Record(ctx, db, action string, targetType string, targetID string, before, after any)
```

actor 取 ctx 里的用户（系统任务用 `"system"`），ip 取 chi `RealIP`。后续每个写接口都调用。

### 4.5 HTTP 装配 `server/internal/api`

- `NewRouter(deps)`：chi 中间件 `RequestID`、`RealIP`、`Recoverer`、自写 `slog` 访问日志（不记录 `/sub/` 路径的 query 与 token，见步骤 15）、`Compress(5)`。
- 路由分组：`/api/auth/*` 公开；`/api/*` 其余挂 `auth.Middleware`；`/api/agent/*` 在步骤 05 另挂 agent token 校验；剩余全部 → `web.Handler()`：存在的静态文件直接返回（带 `Cache-Control: public, max-age=31536000, immutable` 给带 hash 的 assets），否则返回 `index.html`。
- 统一错误 JSON：`{message: string}`；参数校验错误 400。

### 4.6 前端

- starter 的 JWT 流程直接可用；确认 `auth/context/jwt/utils.ts` 的 `tokenExpired` 里那个 `alert('Token expired!')` 改为 toast + 跳登录页。
- `sections/account/account-change-password.tsx` 接 `POST /api/auth/password`，挂到 `/dashboard/settings/security`。
- 登录页文案改中文，去掉"注册"和第三方登录入口（`auth/view/jwt/sign-in-view.tsx`）。

| 类型 | 内容 |
|---|---|
| REST | `POST /api/auth/sign-in`、`GET /api/auth/me`、`POST /api/auth/password` |
| 表 | `users`、`settings`、`audit_log` |

## 6. 验收标准

- [ ] 首次启动日志打印初始密码；`data/vm.db` 与 `data/jwt.secret` 生成；再次启动不重复创建
- [ ] 前端用 `admin` + 初始密码登录成功，进入 dashboard；刷新页面仍保持登录
- [ ] 连续 5 次错误密码后返回 429，15 分钟后恢复（测试时可把窗口临时改短）
- [ ] 改密码成功后旧密码失效；`audit_log` 出现 `action='auth.password_change'`
- [ ] 未带 token 访问 `/api/auth/me` 返回 401，前端跳登录页
- [ ] 直接访问 `/dashboard/xxx`（不存在的前端路由）返回 `index.html`，由前端路由处理
- [ ] `go test ./internal/auth/...` 覆盖 argon2 校验、JWT 过期、限速

## 7. 风险与注意

- `modernc.org/sqlite` 首次编译慢（几分钟），正常。
- goose 迁移只增不改；写错了新增一条修正迁移。
- `sessionStorage` 存 token 意味着关标签页即退出，是 starter 默认行为；要改 `localStorage` 只需改 `auth/context/jwt/constant.ts` 与 `utils.ts`，此处不改。
