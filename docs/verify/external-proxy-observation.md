## 自动验证

- 配置解析：JSON/JSONC、字符串中的 URL、尾逗号、未知协议、密码/UUID/私钥字段不进入 DTO、管理 API 入站排除、读取大小限制。
- Linux 发现：自定义二进制和服务、多进程、相对配置路径与 `-D` 顺序、PID 对应 socket inode、TCP/UDP 区分、配置读取失败保留上次结果。
- 数据库：含未 checkpoint WAL 的 fixture 能读到最新提交；采集前后源 DB/WAL/SHM 字节完全一致。
- RPC：分别断言 sing-box 与 Xray 的服务全名以及每个请求 `reset=false`，拒绝非字面 loopback 地址和非法端口。
- Agent 写保护：外部服务的直接命令、消息队列、启动恢复、日志维护、统计和 purge 均拒绝；资源替换、drop-in、强制 observe 模式均关闭管理。
- 服务端：完整分页原子提交、旧 session/序号拒绝、分片缺失/超时/混合元数据/未知字段/超限拒绝、断线与缺失标为过期、历史数据保留、独立统计不写结算表。
- HTTP：真实 WebSocket 协商下，外部节点 install/restart/apply/rollback/logs/inbound/cert/advanced 返回 409；观测需 JWT；刷新只接受空结构，不接受文件路径。
- 前端：缺失用量与 0 分开；外部、未知、离线节点不能进入托管编辑。21 项前端测试通过；TypeScript 和生产构建通过。
- 本地 Linux 隔离容器执行观察器与核心管理测试通过。Alpine + OpenRC 真实安装、启动、停止、卸载通过；`--purge-core` 缺少所有权记录时拒绝，外部同名文件 SHA256 不变。容器不提供完整宿主 cgroup/init，相关 OpenRC 环境提示不等于完整 VPS 系统验收。

## 支持边界

- Linux amd64、arm64 提供静态探针；实际两台节点和容器运行验证为 amd64，arm64 单独验证交叉构建。
- 宿主机普通进程、systemd、OpenRC 可观测；托管核心安装仍要求 systemd。
- 配置文件表示声明，PID socket 表示绑定；都不能单独证明代理客户端端到端可用或某次热重载成功。
- 多文件展示各文件的入站声明，并标记合并生效结果未确认；不模拟所有核心版本的合并规则。
- 非宿主网络命名空间仅展示可读取的内部进程/配置/绑定信息，明确提示没有公网端口映射；不访问该命名空间的 loopback API，不宣称 rootless/bridge 全面适配。
- 手动绑定放在节点本地 Agent YAML。网页给出填写示例，不提供远程任意路径读取或原文件下载。
- 外部日志正文、配置编辑、统计清零、自动补装 API、重启和卸载不属于观测功能。
- 当前统一每 30 秒采集，页面每 5 秒取最新快照；配置/统计失败不会终止其他节点或其他实例。首次未完成读取以及超过 90 秒未更新的数据标为过期。
