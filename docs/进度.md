### 步骤 02 · 服务端基础与认证 —— 复核完成度 96%

- **配置**：`VM_` 前缀环境变量全套（LISTEN / DATA_DIR / PUBLIC_URL / JWT_SECRET / TZ / LOG_LEVEL / TRUSTED_PROXIES），数据目录 0700、`jwt.secret` 0600，JWT 密钥不足 32 字节直接启动失败。
- **存储**：SQLite（`modernc.org/sqlite` 纯 Go 驱动，`CGO_ENABLED=0` 可编译）+ goose 迁移。`0001_init.sql` 建 `users` / `settings` / `audit_log` 三表。
- **认证**：argon2id 密码校验（带 4 并发闸 + 排队 5s 超时返 503）、JWT 签发与中间件、首启生成初始管理员并 WARN 打印一次性密码、改密、登录限流（同 IP 连续失败第 6 次起返 429 带 `Retry-After`）。
- **审计**：`audit_log` 记 `auth.sign_in` / `auth.password` 等动作，来源 IP 按 `VM_TRUSTED_PROXIES` 决定是否采信 `X-Forwarded-For`（fail-closed，不用 chi 的 RealIP）。
- **前端**：登录页接通、刷新保持登录（sessionStorage + `GET /api/auth/me`）、会话过期跳 `?reason=expired`、改密页挂在 `/dashboard/settings/account`。
- **单测**：auth 19 个、config 9 个、store 5 个、api 的认证相关 14 个。
- **未闭环**：0600/0700 权限位断言在 Windows 上被 `runtime.GOOS != "windows"` 绕过（不是 `t.Skip`，测试输出里看不出来），要到 Linux 真机或 CI 才真跑。
