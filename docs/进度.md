## 4. 当前系统实际能做什么

**能**：起服务端 → 首启拿到一次性管理员密码 → 登录 → 建节点 → 拿 token 与一键安装命令 → 改密 / 删节点 / 重置 token，全过程有审计。agent 二进制能在本机跑 `--once` 输出 hello + metrics，能对着任意 WS 端点做握手、发 hello、按间隔发 metrics、断线按退避重连。

**2026-09-13 起还能**（步骤 05）：agent 真的连得上服务端了——装好 agent 的机器会出现在节点列表里，`online` / `last_seen` / `host` 都是真值；浏览器连 `/api/ws` 能每秒拿到一帧全量快照。协议两端已经真实联调过（不再是步骤 04 那个一次性的 mock hub）。

**不能**：界面上还看不到这些——`/dashboard` 总览、代理、订阅、告警四页仍是占位页，快照目前只有命令行客户端在消费。**前端消费 snapshot 是步骤 06 的工作**。历史曲线（08）、ping（09）、代理相关（10–17）全部未开工，快照里的 `traffic` / `ping` / `core` 三个字段恒为空。

### 已知缺陷（不挡路，但别忘了）

6. **`install.sh` 的 awk 改配置有缺陷，且本地就能复现**（不是"待真机"）：匹配规则 `/^[[:space:]]*token:/` 会命中任意缩进层级的同名键，并把它提升到顶层，产出重复 key 的 YAML，yaml.v3 直接硬解析失败；配合 unit 里 `Restart=always` / `RestartSec=3` 就是永久重启循环。今天不触发（当前 schema 没有嵌套的 server/token 键），但**步骤 11/13 要加的 `core:` 段正好是这个形状**。另：`--base` 能绕过 `ws://` / `wss://` 格式校验；参数值缺失时静默 `exit 1`，usage 永远看不到。
7. **前端三处**：① 「地区」填过之后清不掉——清除按钮给的是 `null`，schema 是 `z.string()`，报英文默认错且对话框不关（`rhf-autocomplete.tsx:86`）；RHFDatePicker 对非法日期有同类路径（塞 Dayjs 对象进 `z.string()`）。② 行内「重置 token」是**零确认**的破坏性操作，线上已装 agent 当场失效只能重装，而风险相当的「删除」反倒有二次确认。③ 节点列表在点验所用的窗口宽度下 DataGrid 实际会横向溢出（固定列宽合计下限 1042px > 可用宽度），偏离记录 27「1440 宽不再需要横向滚动」是卡在边界上的说法。
8. **`POST` / `PUT /api/servers` 的响应体里 `host` 恒为 `null`**（写死传 nil），而 `GET` 列表与详情会带 `host`。步骤 05 之后会出现返回体不一致。
9. **agent 退出不发 WebSocket close 帧**（`client.go` 用 `defer conn.CloseNow()`），服务端侧看到的会是异常断开而不是正常关闭——写 hub 的离线判定时要知道这一点。
10. **metrics 的 `ts` 会周期性跳秒**：采样循环是"先采集发送、再 `timer.Reset`"，真实周期是 `interval + 采集耗时`，而 `ts` 按秒截断，1 秒分辨率下会出现空洞（步骤 06/08 入库后就是曲线上的缺口）。

### 测试与验证的系统性空洞

11. **`-race` 从来没跑过**（步骤 05 之后更要紧：hub 是第一块真并发代码，只做过一轮人工对抗性审查）：本机 `-race requires cgo` 且 PATH 无 gcc，CI 的 go job 也没加这个 flag。而 transport 的退避重连、hostCache 的 mutex、ratelimit 的并发计数都是明确的并发点。（复核中另发现 transport 测试自身带一处数据竞争，CI 一旦开 `-race` 会直接失败。）

13. **`agent/cmd/agent` 包 0% 覆盖**：244 行 main.go 里 `handleMessage`（config 处理链）、`clampInterval`、`hostCache.get`（5 分钟 TTL）、`loadConfig`、`runOnce`、`sampleLoop` 全部无测试。
